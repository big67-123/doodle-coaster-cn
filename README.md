# 涂鸦过山车 · Doodle Coaster CN

**▶ 在线试玩：<https://big67-123.github.io/doodle-coaster-cn/>**（手机浏览器直接打开，不用装任何东西）

随手画一条线，它就会变成一条真的过山车轨道 —— 然后第一人称坐上去。

原版是 [らくがきコースター / Doodle Coaster](https://rakugaki-coaster.pages.dev/)（作者 [@kikuchitls](https://x.com/kikuchitls)），
这个仓库是在它基础上的中文衍生版：**界面全中文**、加了**速度 / G 值仪表**、加了**可调电磁弹射（100–10000 km/h）**、
留了一个**自己设计轨道的口子**（文件槽 + 页内粘贴 + 可视化编辑器）。

零依赖、零构建：仓库根目录就是站点根目录，扔进任何静态托管都能跑，直接双击 `index.html` 也能跑。

## 玩法

| 操作 | 说明 |
|---|---|
| 画轨道 | 在屏幕上一笔画一条线，松手即生成轨道（至少要 25 米） |
| 出发 | 点「▶ 出发」按重力起步；点「⚡ 电磁弹射」按滑杆上的速度弹射出去 |
| 弹射速度 | 滑杆是对数刻度，100 → 10000 km/h；四个快捷档 300 / 1k / 3k / 10k |
| 仪表 | 乘坐时左下角实时显示速度（km/h）和 G 值；G 条按对数刻度，白线是本次峰值 |
| 慢动作 | 右下角按钮或键盘 `S` 在 1× / 1/10 / 1/50 之间切换（弹射太快时会自动切） |
| 轨道工坊 | 右上角 🛠。列出 `tracks.js` 里的轨道，可粘贴 JSON 试跑、导入导出、进编辑器 |
| 编辑器 | 拖圆点移动控制点，点空白处插点，双击圆点删点，`Ctrl+Z` 撤销 |
| 分享 | 成绩卡上有分享链接。手绘轨道用原版的 `#t=` 紧凑编码，设计出来的轨道用 `#j=` JSON 编码 |

## 想加一条自己的轨道？

打开 `tracks.js`，往数组里追加一项：

```js
{
  id: 'my-ride',                 // 英文/数字标识，用来区分
  name: '我的轨道',
  ground: 70,                    // 地面高度（米），决定 h = 0 落在哪
  launch: 300,                   // 默认弹射速度 km/h；填 0 或省略 = 重力起步
  note: '随便写点什么',
  points: [[0, 0], [40, 30], [80, 44], [120, 6], [160, 0]],
}
```

`points` 是控制点数组，每一项是 `[x, h]`：

- `x` = 距起点的米数
- `h` = **离地高度**（向上为正，单位米，最低 0）。不用关心画布大小。
- 这些点就是 Catmull-Rom 样条的控制点本身，不做额外平滑 —— 你放哪，轨道就过哪。
- 内置了 `loopPoints(cx, ch, r)` 可以生成一个立环的控制点，见 `vertical-loop`。

改完刷新页面，就能在「轨道工坊 → 我的轨道」里看到并试跑。

## 物理说明（这块是重点）

单位就是米和秒：`1 单位 = 1 米`，速度变量就是 m/s（所以 km/h 只要 × 3.6）。

### 与原版的兼容性

普通乘坐（速度低于 60 m/s ≈ 216 km/h）**和原版逐位一致**，这不是估计，是测试断言的事实
（`test/physics.test.mjs` 拿原版实现跑出的黄金基线逐帧比对）。超过 60 m/s 后自适应子步开始起作用，
偏差在 0.008% 量级，而且比原来更准。

### 三处改动

| 改动 | 原因 |
|---|---|
| **自适应子步** | 原版固定 `1/240 s`。10 000 km/h = 2778 m/s 时每子步前进 11.6 米，而轨道采样间距只有 0.25 米 —— 会直接穿过轨道。现在每子步最多前进一个采样间距（`h = min(SUB, 0.25/|v|)`），低于 60 m/s 时它恰好等于原值。 |
| **阻力封顶** | 原版 `DRAG·v²` 在 2778 m/s 下是 6173 m/s²（约 629 G），半秒内把车吃光。街机模式封顶在 3 m/s²（`v ≤ 61.2 m/s` 时与原式**逐位相同**）；工坊里的「真实空气阻力」开关可以切回原式，图一乐。 |
| **限减速制动** | 原版在最后 14 米把速度**瞬间钳位**到 `max(1.5, 1.15·rem)`。普通速度下看不出来，但高速时那是一次 2300 m/s 的瞬跳。现在改成受 25 m/s² 限制的真实减速；把制动力设成无穷大时就退回原版行为。 |

### 电磁弹射怎么算的

弹射段长度 `L = clamp(轨道长 × 0.25, 25, 300)` 米，加速度 `a = (v² − v₀²) / 2L`。
在弹射段内速度由位置决定（`v = √(2as + v₀²)`），是**运动学牵引**而不是积分出来的 ——
10 000 km/h 需要约 4700 G 的加速度，任何积分器都扛不住。进入弹射段后是恒定加速度，
所以位移用梯形公式 `(v₀+v₁)/2·h` 是**精确解**，弹射时长与步长无关（实测收敛到 0.006%）。

达到目标速度后无缝交回原有动力学。

### 高速下的终点

10000 km/h 跑完一条 500 米轨道只要 0.18 秒，这是物理事实，不是 bug：

- **街机模式**：末端制动来不及发力，列车以近全速冲过终点（实测 2775 m/s）。
- **真实阻力模式**：空气在 0.45 秒内吃光速度，最后在 14 米制动区被钳位。

两种都以 `ended = true` 正常结束，不 NaN、不倒退 —— 这些都有测试盯着。

## 本地开发与测试

也可以在本地直接双击 `index.html`（`physics.js` / `tracks.js` 都是经典 script，`file://` 下也能加载）。

```bash
node --test test/physics.test.mjs test/tracks.test.mjs   # 物理 + 轨道校验
node _tools/serve.mjs 8899                               # 本地静态服务器
```

`?test=1` 会挂出 `window.__olc`，可以在浏览器控制台里直接驱动：
`__olc.loadDef(def)`、`__olc.setLaunch(10000)`、`__olc.stats()`、`__olc.dry({launchKmh:10000})`、
`__olc.enterEdit(def)`、`__olc.exportDef()`、`__olc.shareHash()` 等。

```bash
node _tools/bench.mjs        # 构建耗时
node _tools/converge.mjs     # 空间步长收敛性
```

### 文件结构

| 文件 | 作用 |
|---|---|
| `index.html` | 全部 UI、渲染、i18n、仪表、弹射、工坊、编辑器 |
| `physics.js` | 无 DOM 的纯数学：几何、积分器、无头 `simulate()`。既是浏览器里的经典 script，也能被 Node `require()` |
| `tracks.js` | 轨道定义槽 + 校验器，`file://` 下也能加载 |
| `test/` | `node:test` 测试，含从原版实现采集的黄金基线 `golden.json` |

> 注意 `physics.js` 必须按 CommonJS 语义加载。仓库里**故意没有** `package.json` 的 `"type": "module"`，
> 否则 Node 会把它当 ESM，`require()` 拿不到导出。
